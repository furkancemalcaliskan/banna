# Support

Use GitHub issues for reproducible bugs, documentation gaps, and focused feature
proposals. Search existing issues first and include:

- Banna version or commit;
- operating system and Rust version;
- ABP version and selected UI target when relevant;
- the exact command or workflow;
- expected and actual behavior; and
- a minimal reproduction with secrets removed.

Community support is best effort. A response time, fix date, or compatibility
commitment is not guaranteed.

Do not use a public issue for suspected vulnerabilities. Follow
[SECURITY.md](SECURITY.md). Questions about contributing belong in the issue
that defines the proposed change; the development workflow is documented in
[CONTRIBUTING.md](CONTRIBUTING.md).
