# Banna v0.1.0

Banna v0.1.0 is the first public binary release of the terminal-first code
generator for existing ABP applications.

## Highlights

- Generate domain, application, Entity Framework Core, permission, mapping,
  localization, and UI layers from one entity definition.
- Use the same workflows through the interactive `banna` TUI or deterministic
  `banna-cli` commands suitable for scripts and CI.
- Generate Razor Pages, Vue components hosted by MVC, standalone Angular CRUD
  features, and an optional React Native application base.
- Detect and switch supported Basic and LeptonX themes, apply removable
  Bootstrap overrides, and generate ThemeChanger integration for MVC and
  Angular applications.
- Preview changes in an isolated workspace with `--dry-run`, retain generation
  history, and regenerate after editing fields or UI metadata.
- Resolve current web tooling without generated dependency version locks and
  keep the latest ABP CLI in Banna's private cache.

## Binary Downloads

The release publishes native bundles for:

- Linux x86-64 and ARM64;
- macOS Intel and Apple Silicon; and
- Windows x86-64 and ARM64.

Each bundle contains `banna`, `banna-cli`, the README, the Banna license, and
licenses/notices required by embedded third-party content. Verify the selected
archive with its adjacent `.sha256` file or the aggregate `SHA256SUMS` manifest
before extracting it.

GitHub automatically displays source-code archive links for every tag. Those
links are not Banna distribution artifacts; the files named
`banna-v0.1.0-<target>` are the supported executable bundles.

## Compatibility And Safety

- Banna modifies an existing ABP solution and expects the solution's matching
  .NET SDK to be installed.
- Start from a clean Git worktree, run `--dry-run`, and review generated diffs.
- Commercial Angular LeptonX is detected but is not rewritten as LeptonX Lite.
- The public CLI and generated-output contracts may evolve before `1.0.0`.

See the [User guide](../user-guide.md) for installation, field definitions,
generation targets, themes, localization, regeneration, and troubleshooting.

## Supply Chain

All six bundles are built from the signed annotated `v0.1.0` tag on native
GitHub-hosted runners. The release includes SHA-256 checksums and GitHub build
provenance attestations. Release publication runs only after repository,
dependency, test, package, and all-platform binary checks succeed.
